# DialogBrain Cookie Sync Extension

Chrome extension for syncing Instagram/LinkedIn sessions with DialogBrain.

**Version: 1.1.13-stage**

**⚠️ STAGE VERSION** - Connects to stage-api.dialogbrain.com

## Installation

1. Download this repository as ZIP (Code → Download ZIP)
2. Extract the ZIP file
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode" (toggle in top right)
5. Click "Load unpacked"
6. Select the extracted folder

## Updates

To update, repeat steps 1-6. The extension will be replaced with the new version.
